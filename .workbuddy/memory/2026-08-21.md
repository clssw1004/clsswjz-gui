## 修复：自动记账生成的支出金额为正数

- 根因：`lib/services/recurring_config_service.dart` 的 `generateForConfig` 直接使用 `config.amount`（配置表金额恒为正），未按收支类型规范化符号，导致支出账目被记成正数。
- 项目约定：支出存负数、收入存正数（`modern_item_form` 类型切换用 `-abs()`、`statistic_service` 用 `expense.abs()` 求和）。
- 修复：生成账目前按类型处理 `amount = type == expense ? -config.amount.abs() : config.amount.abs()`。
- 所有生成入口（自动扫描 `generateDueRecords` / 手动 `generateNow`）均走 `generateForConfig`，一处修复全覆盖；`flutter analyze` 通过。
